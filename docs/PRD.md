# PRD — MAGI 个人日程系统（v1.3）

单用户产品：用户即大一学生本人。本文是开发用精简需求；完整交互原型与设计基调见 `magi-docs/magi-docs.html`。

> v1.1 变更：三端全功能；课程改为按日期到日期（废除周次/奇偶周）；任务优先级改为四象限（紧急×重要）；新增「截图识别」模块；AI 双模型（视觉识图 + DeepSeek 规划）；移除 Microsoft To Do。
> v1.2 变更：识图模型定为 Qwen-VL；部署复用博客 Nginx（弃 Docker/Caddy）；课程支持表格批量导入；明确 AI 走瘦代理（不用编排平台）；域名与截图隐私均已确认。
> v1.3 变更：新增「常驻可见层」——桌面右侧便签（桌面层，显示任务+待办）+ Android 小组件（Redmi K70 Ultra / HyperOS）；均为简报数据只读投影，并入 S3 里程碑交付；桌面便签固定屏幕右侧、不置顶、置于桌面层。

## 1. 原始需求 → 模块映射

| 原始需求 | 模块 |
|---|---|
| 添加日程 | M2 课程表（按日期范围）+ M3 日程事件（一次性/重复） |
| 管理任务 | M4 任务管理（四象限优先级） |
| 智能安排任务 | M6 智能安排引擎（DeepSeek 规划 + 贪心降级） |
| 今天有什么课 / 带什么书 | M1 今日简报 + M7 提醒推送 |
| 截图/消息识别成任务 | M5 截图识别（视觉模型识图） |
| 桌面右侧便签 / 手机小组件 | M9 常驻可见层 |
| （补充）服务器利用 | M8 数据同步与安全 |

## 2. 关键决策（已定，勿反复）

1. 形态：Flutter 一套代码，三端全功能——Windows / MX Linux / Android（功能一致，非「一端为主其余只读」）。
2. Microsoft To Do：**不使用**（无课程/四象限模型，对本项目无增益）。
3. 课程制度：**按具体日期到日期**，一条课程 = 星期几 + 起止时间 + 起止日期 `[start_date, end_date]`；无周次、无奇偶周。
4. 后端 FastAPI + SQLite，部署为 systemd 服务 `uvicorn`，复用博客现有 Nginx + certbot（弃 Docker/Caddy）；推送自建 ntfy（topic 随机长串）。
5. AI 双模型分工（瘦代理，不用可视化编排平台）：**视觉模型 = 通义千问 Qwen-VL，只识图**（截图 → 结构化任务条目）；**DeepSeek 只做总体任务规划**（四象限判定 + 时间排程）；规划失败降级贪心算法。
6. 优先级 = 四象限（艾森豪威尔矩阵：紧急×重要），AI 首判 + 用户手动覆盖。
7. 离线优先：本地 SQLite 为直接数据源，服务器是同步中枢而非必需依赖。
8. 课程录入：支持手动逐门录入 + 表格批量导入（Excel/CSV/iCalendar，解析为日期制课程）。
9. 常驻可见层：桌面右侧便签（桌面层）+ Android 小组件，均为简报数据（今日课程 / 任务 / 最急 DDL）的只读投影，并入 S3 里程碑一起交付。

## 3. 功能模块

### M1 今日简报（首页）

- 布局：日期头 → 今日课程/日程时间轴 → 带书清单 → 今日任务（按四象限分组）→ MAGI 建议卡。
- 底部 Tab：今日 / 课程表 / 任务 / 截图 / 设置。
- 今日课程 = 今天 ∈ `[start_date, end_date]` ∧ weekday 匹配（日期制，直接日期判断，无周次计算）。
- 带书清单：今日课程教材自动汇总去重；勾选「已装包」当日有效（次日 00:00 重置）；可添加自定义物品（仅当日）。
- 今日任务：四象限分组，每组内按截止时间升序；今天到期或已过期未完成的红色置顶；每组最多显示前 3，其余折叠。
- MAGI 建议卡：引用最近一条未处理/已接受的时间块；接受即落库，忽略仅收起。
- 空态：无课时显示「今日无课 · 待机日」，带书清单隐藏。

### M2 课程表

- 课程 = 日期范围规则：`name + weekday(1-7) + start_time/end_time + start_date/end_date + room + teacher + textbook[]`（≤6 本）。
- 录入方式：手动逐门录入 + 表格批量导入（Excel/CSV/iCalendar，解析为上述日期制字段；列映射在导入向导中可调）。
- 同名课一周多次（如高数周一+周三）= 多条记录，可选标记「同组」共享教材。
- 视图：周视图（列=周一至周日，行=时间段）+ 月视图（日期格子，显示当日课程与事件）；今日列高亮。
- 冲突检测：同 weekday ∧ 时间区间重叠 ∧ 日期范围有交集 → 拒绝保存并列出冲突课程。
- 删除需二次确认；课程被任务引用时只解除关联不级联删任务。
- 学期设置（设置页）：学期名 + 整体起止日期（仅用于视图默认范围与学年归档，不参与单课匹配）。

### M3 日程事件

- 字段：标题*、开始/结束时间*、全天、地点、备注、提醒（提前 N 分钟）、重复规则（JSON：freq/interval/until；MVP 支持每天/每周/每两周）。
- 事件与课程在日视图叠加显示；一次性事件（考试、实验、班会）是它的主要用例。

### M4 任务管理

- 字段：标题*（1-50 字）、课程关联（可选 FK）、截止时间、**四象限**（重要紧急/重要不紧急/紧急不重要/不紧急不重要）、预估时长（5-480 min，默认 30）、备注、状态。
- 状态：待办 / 进行中 / 已完成 / 已放弃；勾选在待办与已完成间切换；长按可放弃。
- 四象限判定：AI 首判（输入 = 截止时间 + 标题语义 + 课程关联），用户可在任务详情手动拖拽改象限；离线/无 AI 时用规则兜底（有截止且临近→紧急；有关联课程→重要）。
- 红色警示：距截止 < 72h → 截止徽标红色并置顶；过期显示「已过期 N 小时」。
- 列表页签：四象限（默认）/ 进行中 / 已完成；象限内按截止时间升序（无截止最后）。
- 无截止任务不参与红色警示与今日到期置顶，智能安排按优先级兜底。

### M5 截图识别（消息/图片 → 任务）

- 入口：底部 Tab「截图」；粘贴剪贴板图片 或 选择本地图片（三端均支持）。
- 流程：上传/本地图片 → **Qwen-VL 识图** → 输出结构化候选任务（标题、截止时间、关联课程、紧迫度线索）→ 用户确认/编辑后入库。
- 典型截图：微信/QQ 聊天记录（作业、通知、收班费）、课程群通知、作业清单、考试安排。
- 期待快照：识别结果以可编辑卡片列出，逐条「确认入库 / 修改 / 丢弃」；未确认不入库。
- 边界：识别模型只负责「提取事实」，不擅自建任务；涉及明确截止日期的提取为 due，其余留待 AI 规划时判定四象限。

### M6 智能安排引擎

- 触发：简报页 / 任务页「安排今天（明天）」按钮 → `POST /ai/plan {date}`。
- 输入上下文：当日课程+事件占用时段、待安排任务（标题/四象限/截止/预估/课程）、作息偏好（wake/sleep/lunch/gap_min/block_min）。
- 双模型分工：截图识图已由 M5 的视觉模型完成；本模块用 **DeepSeek** 做「四象限复核 + 时间排程」，输出 `[{task_id, start, end, reason}]`。
- 硬约束：不与占用重叠、单块 ≥25min、块间隔 ≥10min、重要紧急优先、reason ≤20 字；四象限顺序 = 重要紧急 > 重要不紧急 > 紧急不重要 > 不紧急不重要。
- 服务端四步校验：JSON 可解析 → task_id 存在 → 时间合法且在作息窗 → 无重叠；失败条目剔除；全败转贪心。
- 贪心算法（确定性纯函数）：按（象限序，截止升序）排序，待机段顺序填充，块长 = min(预估, 90, 段剩余)，块间 +10min 缓冲；一个任务只排一块。
- 客户端：建议列表逐条 接受（时间块 status=suggested→accepted 并入日程）/ 拒绝。
- 引擎徽标展示 ENGINE: DEEPSEEK / GREEDY；任何失败不弹错误框。

### M7 提醒推送

| 提醒 | 触发方 | 通道 | 默认 |
|---|---|---|---|
| 晨报（作战简报浓缩） | 服务端 APScheduler | ntfy | 每天 07:00 |
| 出击提醒（课前） | 客户端 | 本地通知 | 提前 20 min，含教室与应带教材 |
| 任务到期汇总 | 服务端 | ntfy | 每天 09:00 |
| 截止前催办 | 客户端 | 本地通知 | 截止前 60 min |

- ntfy topic 为随机长串（简单鉴权）；通知点击深链直达简报页。
- Android 13+ 运行时申请通知权限；桌面端（Win/Linux）走系统通知或 ntfy 客户端。

### M8 数据、同步与安全

- 离线优先：读写直达本地 drift；写操作入同步队列（FIFO）；触发时机=App 启动 / 变更后 30s 静默 / 网络恢复。
- 冲突：last-write-wins（updated_at 较新者胜）；积压 >500 条改全量比对。
- 认证：单账号密码换长期 Token（客户端存系统安全存储）；密码、DeepSeek key、视觉模型 key 只存服务端环境变量。
- 导出/导入：全量 JSON（按日期命名），导入整体替换 + 二次确认。
- EVA 文案：今日作战简报 / 出击提醒 / 待机；红色仅限 DDL、冲突、失联三种语义。
- 三端数据一致：通过同一服务器同步，任意一端变更经队列推至服务器再拉取到其余端。

### M9 常驻可见层（桌面右侧便签 + Android 小组件）

- 定位：把 M1 简报投影到 App 之外，不打开 App 也能随时看到「今天有什么课、要带什么、哪件事最急」。数据源与 M1 简报共用同一份本地 drift 聚合结果，实时更新，不另维护一份。

**桌面右侧便签（Windows / MX Linux）**

- 形态：无边框方形窗口，固定在屏幕右侧；置于桌面层（不置顶），被其他窗口覆盖，按 Win+D / 显示桌面时可见，不遮挡任何窗口。
- 内容：今日任务（四象限分组）+ 待办清单（无 DDL 项）+ 最急一条 DDL（距截止 < 72h 红色）；点击任务唤起主窗编辑。
- 交互：尺寸 / 位置记忆到本机设置；可手动显示 / 隐藏；点击深链回主窗。
- 技术：Windows 将窗口钉到桌面 WorkerW 层（Win32，同桌面便签 / Rainmeter）；MX Linux 用 EWMH `_NET_WM_WINDOW_TYPE_DESKTOP` 置于桌面层。
- Linux 注意：MX Linux 探测 X11 / Wayland；Wayland 下无桌面层协议时降级为普通贴边窗口，可最小化到桌面查看。

**Android 小组件（Redmi K70 Ultra / HyperOS）**

- 形态：今日课程列表 + 今日任务摘要（四象限色点）+ 最急 DDL，点击跳转 App 对应页。
- 刷新：`home_widget` 桥接；App 内数据变更后主动 `updateWidget`，叠加系统定时刷新（Android 组件最小 30 min）。
- HyperOS 注意：引导用户关闭省电限制、加入自启动与通知白名单，否则后台刷新可能被系统杀掉。

## 4. 非功能需求

- 性能：冷启动 ≤2s；本地写 ≤100ms；AI 安排 P95 ≤8s、贪心 ≤100ms；截图识别 P95 ≤8s；增量同步（≤50 条）≤5s。
- 兼容：Android 8.0+（minSdk 26）；Windows 10/11；MX Linux（Debian 系）；深色模式随系统；桌面端与移动端功能对齐。
- 可用性：服务器 restart=always；无网络全功能可用；同步失败静默重试。
- 隐私：仅暴露 443；数据只在手机/桌面 ↔ 自有服务器流动；外呼仅服务端调 DeepSeek（规划）与 Qwen-VL（识图），均为任务/截图数据（截图经自有服务器转发给 Qwen-VL，用户已确认接受）。
